# n8n 智能咨询分类器 - 用户使用手册

## 产品简介

本产品是一个自动化客户咨询处理系统，能够：
- 自动接收客户咨询信息
- 使用AI分析客户意向（高/中/低）
- 高意向客户：立即邮件通知销售团队
- 低意向客户：自动回复确认邮件

## 核心价值

| 对比维度 | 传统方式 | 使用本产品 |
|---------|---------|-----------|
| 响应时间 | 2小时+ | 1分钟内 |

## 快速开始

### 1. 安装 n8n

```bash
# 安装 n8n
npm install -g n8n

# 启动 n8n
n8n
```

访问 `http://localhost:5678` 完成账号注册。

### 2. 导入工作流

1. 登录 n8n
2. 点击右上角 "..." → "Import from JSON"
3. 粘贴 provided JSON 文件内容
4. 点击 "Import"

### 3. 配置 API Key

在 "AI分析" 节点配置你的智谱AI Key：
- 注册：https://open.bigmodel.cn/
- 创建 Key：控制台 → API Keys
- 填入节点 Header：`Authorization: Bearer 你的Key`

### 4. 配置邮件服务

在 "通知销售" 和 "自动回复" 节点配置 SMTP：
- Host: `smtp.qq.com`
- Port: `465`
- User: 你的QQ邮箱
- Password: QQ邮箱授权码（不是密码）
- SSL: `Yes`

获取QQ邮箱授权码：
1. 登录QQ邮箱 → 设置 → 账户
2. 开启 IMAP/SMTP 服务
3. 按提示发短信验证
4. 保存显示的16位授权码

### 5. 激活工作流

1. 点击右上角开关 "Active"
2. 复制 Webhook URL（在 Webhook 节点查看）
3. 将 URL 集成到你的咨询表单/客服系统

## 使用方法

### 接收咨询

客户通过你的网站/表单提交咨询，系统自动调用 Webhook：

```json
POST https://你的域名/n8n-webhook/customer-inquiry
Content-Type: application/json

{
  "name": "张三",
  "email": "zhangsan@example.com",
  "contact": "13800138000",
  "message": "我想咨询产品价格和下单方式"
}
```

### AI 自动分析

系统将客户消息发送给 AI 分析，返回意向等级：
- **高意向**：明确购买意图、询问价格、询问下单方式
- **中意向**：咨询功能、使用方法、适用场景
- **低意向**：闲聊、已购买产品投诉、无关咨询

### 自动处理

**高意向客户**：
- 销售邮箱立即收到通知邮件
- 包含客户完整信息和原始咨询内容
- 销售可及时跟进

**中/低意向客户**：
- 客户收到自动回复邮件
- 内容："感谢咨询，我们会尽快回复"
- 提升客户体验，避免无响应

## 自定义配置

### 修改意向判断标准

编辑 "AI分析" 节点的 `content` 字段：

```
你是一名专业销售分析师，分析客户咨询的意向等级。

判断标准：
- 高：明确表达购买意向、问价格、问下单方式、预约试用
- 中：咨询产品功能、使用方法、适用场景
- 低：闲聊、与产品无关、投诉已购买产品

要求：严格只返回 高、中、低 三个字中的一个。

咨询内容：{{ $json.message }}
```

### 修改邮件内容

编辑 "通知销售" 或 "自动回复" 节点的 `text` 字段，自定义邮件模板。

### 添加更多通知方式

可以在 "判断意向" 节点的 True 分支后添加：
- 企业微信通知（HTTP Request 调用企业微信 API）
- 钉钉通知（HTTP Request 调用钉钉机器人）
- 短信通知（使用 Twilio 或阿里云短信节点）

## 监控与维护

### 查看执行记录

1. 在 n8n 工作流界面点击 "Executions"
2. 查看每次触发的详细日志
3. 检查是否有失败的执行

### 常见问题

**工作流没有触发**：
- 检查 Webhook URL 是否正确
- 检查发送的请求格式是否为 JSON
- 检查 n8n 是否正常运行

**AI 分析失败**：
- 检查智谱 AI Key 是否正确
- 检查账户余额是否充足
- 查看 n8n 执行日志中的错误信息

**邮件发送失败**：
- 检查 SMTP 配置是否正确
- 确认使用的是授权码而非密码
- 检查端口和 SSL 设置
