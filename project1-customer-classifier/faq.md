# n8n 智能咨询分类器 - FAQ

## 安装部署

### Q1: 我不会编程，能使用这个工作流吗？

A: 可以。n8n 是低代码平台，大部分操作是点选。导入工作流后，只需要：
1. 注册智谱 AI 获取 API Key（免费额度）
2. 配置 QQ 邮箱授权码（15分钟搞定）
3. 激活工作流

如果你不想自己配置，可以联系开发者付费代部署（800-1500元）。

### Q2: 需要什么环境？

A: 最低配置：
- 一台能上网的电脑/服务器
- Node.js 16+（推荐 18+）
- QQ 邮箱（用于发通知邮件）
- 智谱 AI 账号（免费注册）

推荐配置：
- 云服务器（阿里云/腾讯云，2核4G，约 100元/月）
- 独立域名（可选，提升专业度）

### Q3: 一定要用 QQ 邮箱吗？

A: 不是。可以用任何支持 SMTP 的邮箱：
- 企业邮箱（推荐）
- 163 邮箱
- Gmail（需要科学上网）
- Outlook

修改 SMTP 配置即可。

## 配置问题

### Q4: 智谱 AI Key 在哪里获取？

A: 
1. 访问 https://open.bigmodel.cn/
2. 注册账号（手机号即可）
3. 控制台 → API Keys → 创建 Key
4. 复制 Key（以 `6AXXX` 开头）

新用户有免费额度，足够测试使用。

### Q5: QQ 邮箱授权码如何获取？

A:
1. 登录 QQ 邮箱 → 设置 → 账户
2. 找到 "IMAP/SMTP服务"
3. 点击 "开启"
4. 按提示发短信验证
5. 验证成功后显示 16 位授权码

**注意**：授权码只显示一次，务必保存好。

### Q6: Webhook URL 是什么？如何集成到我的网站？

A:
1. 激活工作流后，在 Webhook 节点查看 URL
2. 格式：`http://你的IP:5678/webhook/customer-inquiry`
3. 网站表单的 `action` 指向这个 URL
4. 确保表单字段名与工作流中的字段名一致（`name`, `email`, `contact`, `message`）

示例 HTML 表单：
```html
<form action="你的WEBHOOK_URL" method="POST">
  <input type="text" name="name" placeholder="姓名">
  <input type="email" name="email" placeholder="邮箱">
  <input type="text" name="contact" placeholder="联系方式">
  <textarea name="message" placeholder="咨询内容"></textarea>
  <button type="submit">提交</button>
</form>
```

## 使用问题

### Q7: 如何判断 AI 分析的准确度？

A: 测试阶段建议：
1. 手动测试 20-30 条咨询
2. 对比 AI 判断结果 vs 人工判断
3. 调整提示词中的判断标准
4. 将 `temperature` 设为 0.1（降低随机性）

实测准确度：85-95%（取决于提示词质量）。

### Q8: 可以同时处理多个咨询吗？

A: 可以。n8n 支持并发执行，理论上可以同时处理数百个咨询。

限制因素：
- 智谱 AI API 的 QPS 限制（免费版约 10 QPS）
- 服务器 CPU/内存

如果需要高并发，建议使用付费版 API 或升级服务器配置。

### Q9: 如何查看历史咨询记录？

A: 两种方式：
1. **n8n 执行日志**：工作流 → Executions → 查看每次执行的详细数据
2. **添加数据库/表格记录**（推荐）：
   - 在 "判断意向" 节点后添加 Google Sheets 节点
   - 每次咨询自动记录到表格
   - 方便后续数据分析和客户跟进

## 技术细节

### Q13: AI 分析用的是什么模型？

A: 默认使用智谱 AI 的 `glm-4-flash` 模型：
- 速度快（约 1-2 秒返回）
- 成本低（免费额度够用）
- 中文理解好

可以替换为其他模型：
- DeepSeek（`deepseek-chat`）
- 通义千问（`qwen-turbo`）
- Claude（需科学上网）

### Q14: 如何保证数据安全？

A:
1. **数据不存储**：工作流执行完即结束，不保存客户数据到本地
2. **API 通信加密**：所有 API 调用使用 HTTPS
3. **可添加数据脱敏**：在 Code 节点中添加脱敏逻辑（如手机号打码）
4. **私有部署**：可以选择在自己的服务器上部署，完全掌控数据

如果需要存储客户数据，建议：
- 添加数据库节点（MySQL/PostgreSQL）
- 或连接到你现有的 CRM 系统

### Q15: n8n 宕机了怎么办？

A:
1. **监控**：使用 n8n 的 "Error Trigger" 节点，出错时发送通知
2. **重启**：`n8n` 命令重启服务
3. **开机自启**：配置 systemd 或 PM2，服务器重启后自动启动 n8n
4. **备份**：定期导出工作流 JSON，方便快速恢复

推荐：使用 PM2 管理 n8n 进程，自动重启。

## 进阶问题

### Q16: 如何提升 AI 分析的准确度？

A: 四种方法：
1. **优化提示词**：添加更多正例和反例
2. **微调模型**：用你的历史咨询数据微调模型（需一定技术门槛）
3. **多模型投票**：同时调用 3 个模型，少数服从多数
4. **人工复核**：高意向客户自动通过，低意向客户人工复核

### Q17: 可以接入多个销售渠道吗？

A: 可以。修改工作流：
1. 在 Webhook 节点后添加 "Switch" 节点
2. 根据来源渠道（网站/微信/电话）分流
3. 不同渠道使用不同的通知方式和邮件模板

### Q18: 如何集成到企业微信/钉钉？

A: 需要添加 HTTP Request 节点：

**企业微信**：
```json
{
  "method": "POST",
  "url": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的KEY",
  "body": {
    "msgtype": "text",
    "text": {
      "content": "高意向客户：{{ $json.name }}\n咨询内容：{{ $json.message }}"
    }
  }
}
```

**钉钉**：
```json
{
  "method": "POST",
  "url": "https://oapi.dingtalk.com/robot/send?access_token=你的TOKEN",
  "body": {
    "msgtype": "text",
    "text": {
      "content": "高意向客户：{{ $json.name }}\n咨询内容：{{ $json.message }}"
    }
  }
}
```

## 故障排查

### Q19: 工作流没有触发？

A: 检查清单：
1. ✅ n8n 是否正常运行？（访问 `http://localhost:5678`）
2. ✅ 工作流是否激活？（右上角开关是否为绿色）
3. ✅ Webhook URL 是否正确？（复制节点中的 URL）
4. ✅ 请求格式是否为 JSON？（检查 `Content-Type: application/json`）
5. ✅ 防火墙是否开放 5678 端口？

### Q20: AI 分析节点报错？

A: 常见错误：
1. **`Model not found`**：模型名称错误，检查是否为 `glm-4-flash`
2. **`Insufficient credits`**：余额不足，去智谱 AI 控制台充值
3. **`JSON Body not valid`**：请求体格式错误，用 https://jsonlint.com/ 验证

### Q21: 邮件发送失败？

A: 检查清单：
1. ✅ SMTP 配置是否正确？（Host/Port/SSL）
2. ✅ 密码是否填成了授权码？（不是 QQ 密码）
3. ✅ 授权码是否过期？（重新获取）
4. ✅ 端口是否为 465 且启用了 SSL？
